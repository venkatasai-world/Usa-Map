# USA Map Guessing Game

This is a fun **USA map guessing game** built using Python's `turtle` module and CSV data.

---

## 🎯 How it Works

- A blank map of the USA is displayed.
- The user is asked to enter the name of a U.S. state.
- When a correct state is entered, the name appears on the map in the correct position.
- This continues until all states are guessed or the user exits.

---

## 🐍 Technologies Used

- Python `turtle`
- CSV file (for storing state names and coordinates)
- No external libraries needed
